# Project Update : 2020 Sri Lanka Parliamentary Election Results Analysis using Power BI 📊

***🚀 Project Update: Bilingual Election Analysis with Power BI 📊***

This comprehensive project, available in both Sinhala and English, showcases key insights and comparisons across recent elections.

## ✨ Features and Visuals :

- Custom Electoral District Mapping: Designed a 22-district electoral map using Synoptic Designer. 
- District Breakdown: Visualized vote shares for top candidates, with interactive district filtering. 
- Dynamic Dashboards: Dive into district-specific data to reveal impactful voting patterns. 
- Advanced DAX Queries: Built tailored calculations and dynamic text to enhance user insights. 
- Comparative Analysis: Analyzed 2015 Parliamentary Election and compared Presidential Elections (2015, 2019, and 2024) for deeper trends. 
- Engaging Visuals: Used stacked bars, cards, and more for clear, interactive insights.
